# 📸 Photography Blog

A modern, Arabic photography blog built with **React, Vite, and Bootstrap**. The application provides an elegant space to explore photography articles, browse categories, search for posts, and discover detailed photography content through a responsive, dark-themed interface.

## ✨ Features

- **Arabic Interface** – A user interface designed for Arabic content.
- **Article Browsing** – Explore photography articles in an organized layout.
- **Category Filtering** – Filter articles by photography topics:
  - إضاءة (Lighting)
  - بورتريه (Portrait)
  - مناطق طبيعية (Nature)
  - تقنيات (Techniques)
  - معدات (Equipment)
- **Search Functionality** – Find articles using the search feature.
- **Pagination** – Browse articles across multiple pages, displaying six posts per page.
- **Dynamic Post Details** – Navigate to individual article pages.
- **Author Sections** – Display author-related content.
- **Responsive Design** – Adapted for different screen sizes.
- **Dark-Themed UI** – A clean visual experience focused on photography content.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/Om4r-Y4sser/photography-blog.git
   ```

2. **Navigate to the project directory**

   ```bash
   cd photography-blog
   ```

3. **Install dependencies**

   ```bash
   npm install
   ```

4. **Start the development server**

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.
